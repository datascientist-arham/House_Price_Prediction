# House Price Prediction using Machine Learning

## Project Overview
Predicting house prices using machine learning techniques on the Ames Housing Dataset.

## Dataset
- 1,460 Houses
- 80+ Features

## Models Used
- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## Best Model
Gradient Boosting Regressor

## Technologies
Python, Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
